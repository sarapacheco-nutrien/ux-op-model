How UX Creates Impact

Adaptive partnership. Evolving craft.
Meaningful outcomes. Always human.

We partner across the lifecycle – from ideas to outcomes – shifting our engagement to meet the moment.

We accelerate our craft using evolving technologies while preserving the voice of the user as we invent on their behalf.

Through tactical execution and demonstrating the art of the possible, UX translates complexity into clarity, giving users back their time while raising the bar in our digital platforms.

At the core of it all, our work remains deeply human.

Transformation

Where We're Headed
Sophisticated Light-Layer of Design

Figma design artifacts and enhanced user flows as focused output, iterating in real-time with users for key features.

Partnership + Resources

Embedded advisory and design reviews in place of exhaustive design direction. UX-focused steering files and implementation guides that inform repeatable patterns and design standards.

Rise Design System

Component library, design tokens, and detailed documentation — the shared foundation that makes repeatable, scalable UI possible across the Hub.

Stewardship + Art of the Possible

Vision concepts and inventing bar-raising experiences; stewardship of high-stakes, multi-phase workflows to support scalability and future-proofing experience architecture.

Challenges We're Overcoming
01

Time-intensive design for every interaction across all breakpoints.

02

Churn on collective understanding of requirements that results in Figma becoming source of truth.

03

Diminished delivery quality due to unpredictable engagement from engineers on design reviews.

04

Logging design and experience bugs for engineers to address after features have gone to production.

Tier 1

Engineer-Led UI

Changes to existing features leveraging established patterns.

How UX will engage:
  • Pre-work + discoveryNone
  • AdvisoryProduct lane UX designer(s), bi-weekly office hours
  • User flowsUpon request
  • Figma design artifactsNone
  • Design reviewsRequired — feedback at demo stage
  • ResourcesSteering files, delivery kits

Faster delivery with minimal resource impact.

★ Most Common ★
Tier 2

Directional Design

Notable extensions of existing patterns or follow-on phases of larger features.

How UX will engage:
  • Pre-work + discoveryRequirements review, rapid user insights when possible
  • AdvisoryProduct lane UX designer(s), bi-weekly office hours
  • User flowsEnhanced user flow
  • Figma design artifactsDirectional — focus on key workflows, novel layouts
  • Design reviewsRequired — feedback at demo stage
  • ResourcesSteering files, delivery kits

Cross-functional alignment, faster delivery, solidified design direction.

Tier 3

High-Stakes Workflows

Net-new or high-stakes experiences requiring user validation, SME engagement, and an extended runway for deeper exploration.

How UX will engage:
  • Pre-work + discoveryRequirements review, user insights, SME engagement, cross-functional jam sessions
  • AdvisoryProduct lane UX designer(s), bi-weekly office hours
  • User flowsEnhanced user flow
  • Figma design artifactsExtensive directional — key workflows, notable interaction points
  • Design reviewsRequired — ongoing in partnership with engineering through implementation
  • ResourcesSteering files, delivery kits

Deep field trust through engaged delivery, cross-functional alignment, sophisticated user experiences that support system evolution.
